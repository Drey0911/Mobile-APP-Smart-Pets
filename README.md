## Descripción

Smart Pets es una aplicación móvil desarrollada con Flutter y Dart, diseñada para optimizar la gestión de clínicas veterinarias. Permite llevar un control detallado de los perfiles de las mascotas y administrar eficientemente sus citas médicas. El proyecto se integra completamente con el ecosistema de servicios en la nube de Firebase, haciendo uso de **Firebase Authentication** para el acceso y registro seguro de usuarios, **Firebase Storage** para el almacenamiento de recursos multimedia, y **Realtime Database** para garantizar que los datos estén siempre disponibles y sincronizados al instante.
